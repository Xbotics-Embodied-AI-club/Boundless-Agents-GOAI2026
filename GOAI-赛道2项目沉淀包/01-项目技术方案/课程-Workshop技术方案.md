# 身知回响复现 Workshop 技术方案

## 1. Workshop 目标

面向具备基础产品或前端知识、希望理解具身智能产品学习路径的参与者。完成后，参与者应能够：

1. 解释“版本化课程内容—知识检索—规则评估—确定性掌握门槛”的技术路线。
2. 在本机启动 Web Demo，并走通学习、挑战、复述、反馈与点亮流程。
3. 使用自己的小程序 AppID 或官方测试号导入并编译微信小程序。
4. 区分离线规则模式与云端模型增强模式，说明两者的能力边界。
5. 可选完成 CloudBase 环境创建、云函数部署和健康检查。

## 2. 前置条件

- Node.js 20 或兼容版本、npm、Git。
- 运行 Web Demo 无需微信或腾讯云账号。
- 编译小程序需要本人注册的小程序 AppID 或官方测试号。
- 体验云端增强功能需要腾讯云账号、CloudBase 环境，以及本人合法取得的模型 API Key。
- 不应把 AppSecret、API Key、访问令牌或 `.env` 文件提交到仓库。

## 3. 技术路线

```text
版本化课程内容
    ↓
本地知识检索 → 规则证据评估 → 确定性掌握门槛 → 本地进度保存
                       ↑
          可选：CloudBase 云函数 + 模型增强
```

核心学习闭环在没有云环境和模型 Key 时仍可运行；模型只增强自然语言理解，不直接决定是否点亮知识节点。

## 4. 实验安排与验收

### 实验一：启动 Web Demo（约 30 分钟）

- 操作：解压源码，进入源码根目录，依次执行 `npm ci`、`npm run dev`。
- 输入：浏览器打开终端显示的本地地址。
- 预期输出：首页、知识拼图和学习页面可以访问。
- 验收证据：启动终端截图，以及首页截图。

### 实验二：走通确定性掌握流程（约 45 分钟）

- 操作：选择一个知识节点，完成微课、挑战和费曼复述。
- 输入：挑战答案和一段自己的解释。
- 预期输出：页面展示命中证据、缺口或通过结果；只有满足固定规则时节点点亮。
- 验收证据：提交前、规则反馈、节点状态三个界面截图。

### 实验三：导入微信小程序（约 45 分钟）

- 操作：在微信公众平台注册小程序或取得官方测试号；把 AppID 写入 `project.config.json`；使用微信开发者工具导入源码根目录。
- 输入：本人可用的 AppID，不使用仓库中的占位值。
- 预期输出：项目完成编译，可以在模拟器查看页面。
- 验收证据：开发者工具项目配置页和编译成功页面。

### 实验四：部署基础云函数（可选，约 60 分钟）

- 操作：创建或导入 CloudBase 环境，填写环境 ID，部署 `healthCheck` 与 `knowledgePack`。
- 输入：腾讯云账号、已关联的小程序、CloudBase 环境 ID。
- 预期输出：健康检查成功，知识包接口返回结构化数据。
- 验收证据：环境列表、云函数部署结果和调用结果。

### 实验五：启用模型增强（可选，约 60 分钟）

- 操作：把模型 API Key 配置为云函数环境变量，部署 `studyChat` 与 `analyzeProject`，完成一次受限输入测试。
- 输入：本人合法取得的模型凭证和非敏感测试文本。
- 预期输出：模型可用时返回增强结果；超时、无 Key 或结构异常时回退到本地规则模式。
- 验收证据：成功响应与关闭 Key 后的回退结果各一份。

账号创建、关联关系、环境创建、云函数部署和排错步骤详见《04-运行说明/部署说明.md》。

## 5. 最终交付物

参与者至少提交：

1. 可运行的源码副本，不包含密钥和个人隐私数据。
2. Web Demo 启动与核心学习闭环的验收截图。
3. 一份简短复现记录：运行环境、执行命令、实际结果和遇到的问题。
4. 如选择小程序路线，补充 AppID 已配置且编译成功的证据。
5. 如选择云端增强路线，补充 CloudBase 环境、云函数健康检查和回退验证证据。

## 6. 通过标准

- **基础通过**：Web Demo 可运行，核心学习闭环完成，规则证据和点亮结果可解释。
- **小程序通过**：在基础通过之上，小程序使用有效 AppID 成功编译。
- **云端增强通过**：在小程序通过之上，四个云函数部署成功，模型增强和无 Key 回退均验证通过。
- 任何级别都不得在源码、截图或提交记录中暴露 AppSecret、API Key、令牌或真实用户数据。
